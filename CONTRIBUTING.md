# Contributing

The catalogue and comparison site are published at https://cathald.github.io/Carbon_Data_SOD/. When comparing products, keep geographic domain, raster grid, field support, dates, depth datum and shared training data explicit; agreement between maps is not accuracy.

Use [GitHub Issues](https://github.com/CathalD/Carbon_Data_SOD/issues) for additions/corrections. Include the original source DOI/download, release/version, licence, carbon quantity/units, geographic scope, native/output raster size, ground support/depth and Earth Engine ID where available. A discovery lead is welcome if its unresolved status is clear.

For corrections, preserve original IDs and observations; add a new version rather than silently overwriting field data. Do not commit credentials, signed download URLs or raw profile locations merely to demonstrate an example.
