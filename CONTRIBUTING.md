# Repository status and contribution

The maintainer is preparing the summary/comparison analysis in [Comparison](Comparison/README.md). Keep geographic domain, raster grid, field support, dates, depth and shared training data explicit when comparing products. No comparison conclusions are inferred by this candidate release.

Use [GitHub Issues](https://github.com/CathalD/Carbon_Data_SOD/issues) for additions/corrections. Include the original source DOI/download, release/version, licence, carbon quantity/units, geographic scope, native/output raster size, ground support/depth and Earth Engine ID where available. A discovery lead is welcome if its unresolved status is clear.

For corrections, preserve original IDs and observations; add a new version rather than silently overwriting field data. Do not commit credentials, signed download URLs or raw profile locations merely to demonstrate an example. The current public pilot package is aggregate-only.
