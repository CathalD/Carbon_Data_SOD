# Licensing status for the release candidate

The repository currently has no root code/catalogue licence. Public visibility and verified read permissions do not assign one. This candidate makes no blanket open-licence claim for the repository or the copied source datasets.

Recommended maintainer decision: [MIT](https://opensource.org/license/mit) for newly authored repository example code, and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) for authored catalogue metadata/documentation. This proposal has **not** been applied. Confirm the intended scope and rights in existing notebook/code contributions before extending a code licence to them.

Original datasets, papers and upstream code retain their own terms and attribution requirements. Use the source citation/version/licence notes in the catalogue; unresolved source terms remain unresolved rather than being replaced by a repository licence. The release can be reviewed/downloaded now, but should not be announced as a fully open-licensed release until the maintainer selects and applies the repository licences.
