# Carbon State of Data — 0.1.0-rc.1

Historical candidate prepared 15 October 2026, superseded by [release 0.1.0](0.1.0.md). The maintainer subsequently directed that no repository licence be added.

The package provides 13 current catalogue CSVs, a combined JSON catalogue, SHA-256 manifest, source citations/BibTeX, CITATION.cff, read-only Code Editor/Python examples and a verified access report. Download links are public and do not depend on the restricted working Sheet. Source tables connect ground observations → covariates/studies → maps and record geographic scope, native/output grid, field/context support, time and soil depth separately.

The 20-profile baseline pilot returned 20/20 rows with 855/860 predictors available, all QA fields present and all source-layer joins valid. These are workflow results, not a completed national validation or map comparison. Radar-tail/median sensitivity, coastal climate coverage, field-date mismatch and coordinate uncertainty must be addressed before bulk modelling. The original notebook is unchanged.

Public-read grants are verified for 41 hosted references, including Geng at collection scope. SCANFI v2 is public but empty and is excluded from working map examples. Source units/depth/method/uncertainty caveats remain per catalogue. Sothe stock and uncertainty use the maintainer’s 0–1 m assumption; Li’s carbon covers variable modelled peat depth.

The maintainer is preparing a summary/comparison analysis in [Comparison](../../Comparison/README.md). It is intentionally forthcoming: this release adds no inferred rankings, comparison graphics or conclusions on the maintainer’s behalf. Community cores and active circumpolar extraction remain excluded; ABCFlux remains a linked flux resource.

No repository licence has been added, by maintainer instruction. Original resource terms are retained; see [licensing decision](../release_licensing.md). Detailed pilot point/row data are not part of this package. See [DOWNLOADS](../../DOWNLOADS.md), [examples](../../examples/README.md), [citations](../../SOURCES.md) and [access evidence](../public_access.md).
