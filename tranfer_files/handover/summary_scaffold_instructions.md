# Using the summaries scaffold

1. Download `summaries-preview.html` and open it in a browser to explore the layout. Switch Forests/Soils, change the soil depth datum, and select product maps. Panels marked “To add” have no calculated result.
2. Extract `company-repository.zip`. It contains the README, both draft pages and all figures. Upload its extracted README and docs folder to the company repository root.
3. Open `docs/summaries.md` on GitHub and check the images and dropdowns. The README links to both draft pages, and the summaries page links to comparisons.

The preview contains real source-example maps and descriptive charts drawn from prepared soil tables. It does not calculate full-product raster distributions, chosen-area totals or forest plot summaries. Example interval stocks retain the original preparation's eligibility and calculation limitations.

Site stocks and area totals are separate. An area total needs a stated boundary, compatible stock units, depth/pool/year, valid mapped area and missing-data treatment. Soil profiles are not automatically a representative regional sample.
